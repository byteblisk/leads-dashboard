# דשבורד ניהול לידים חכם

דשבורד לניהול לידים לעסק קטן או בינוני, על נתוני דמה. כל ליד מקבל ציון בין 0 ל-100, והדשבורד מסמן לידים חדשים שלא קיבלו מענה תוך 24 שעות ולידים פתוחים שאין איתם קשר שבוע, ומציע לכל ליד את הפעולה הבאה.

הפרויקט נבנה עם Claude Code במסגרת שיעור 3 בקורס מטמיעי AI. הממשק בנוי ב-React עם רכיבי shadcn/ui, מימין לשמאל ועם מצב כהה.

## צפייה

הדשבורד פועל באתר [byteblisk.github.io/leads-dashboard](https://byteblisk.github.io/leads-dashboard/) ב-GitHub Pages.

כדי להריץ מקומית צריך Node.js. נכנסים לתיקייה `app`, מריצים `npm install` ואז `npm run dev`. ההסבר המלא נמצא באפיון.

## אוטומציות ב-Make (מטלה 5)

במטלה 5 חיברתי לדשבורד שתי אוטומציות ב-Make. הראשונה מקבלת ליד חדש דרך webhook, מסדרת אותו בעזרת AI ושומרת אותו בטבלה ב-Airtable שהדשבורד קורא ממנה, כך שהליד מופיע בדשבורד אחרי רענון. השנייה נותנת לליד ציון AI עם Claude: בכרטיס של כל ליד יש כפתור "חשב ציון AI", והציון והסיכום מופיעים בכרטיס ובעמודה "ציון AI" בטבלה. קובצי ה-Blueprint של שתיהן נמצאים בריפו [make-automations](https://github.com/byteblisk/make-automations).
